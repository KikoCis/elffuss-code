# Which suites tests/run-modes.sh runs, and why the others are not run.
#
# One suite per line, without ".mjs". Sections:
#
#   [both]     Code's own suites. Each runs twice against the same server:
#              default mode (node S.mjs) and extension mode (node --import
#              ./lib/x2-mode.mjs S.mjs), where two code extensions are installed
#              and running in the sandbox while the suite works.
#   [once]     Level 2's own suites. They start their own server and set up
#              their extensions themselves, so they run once. x2_live and
#              x2_lifecycle need Open VSX (x2_live only the first time, then
#              tests/.cache): offline they say NOT RUN.
#   [not-run]  "name: reason". They need a live model, a GPU, a local Bridge,
#              the internet or production. They are left out of both modes.
